# Movies App 
**CSS 216 group project**
## Description 
The application allows users to explore movies, search by title, view detailed information, and manage their favorite movies.
## Group Members
* **Zhomart Mankeyev**
* **Aitkaliev Alikhan**

## Main Features
* Movie catalog with interactive movie cards
* Movie search by title
* Detailed movie information
* Favorites management
* Navigation between multiple screens
* Material 3 user interface
* MVVM architecture and UI state management
